# Bayani Chronicles Client

Unity client for **Bayani Chronicles**, a 2D educational role-playing game inspired by **Noli Me Tangere** and **El Filibusterismo** by Dr. José Rizal.

This project was developed as a **team capstone project** and follows a client-server architecture, where the Unity client communicates with a Laravel backend through REST APIs.

---

## 👨‍💻 My Contributions

This was a collaborative capstone project. My primary contributions included:

- Backend API integration with the Laravel server
- Client-server communication through REST APIs
- Implementation of gameplay systems and game logic
- Object-Oriented Programming (OOP) architecture
- Feature integration and system debugging

The project was developed collaboratively with teammates responsible for other gameplay features, UI, assets, and overall game content.

---

## 📖 Overview

Bayani Chronicles aims to make learning Philippine literature more engaging through interactive gameplay.

Players experience selected events inspired by **Noli Me Tangere** and **El Filibusterismo**, complete educational activities, and monitor their learning progress throughout the game.

The Unity client focuses on gameplay while the Laravel backend manages authentication, player data, quizzes, rankings, and persistent game progress.

## 🏗️ System Architecture

```text
                Bayani Chronicles

              Unity Game Client
                     │
                REST API
                     │
                     ▼
             Laravel Backend API
                     │
          Authentication & Business Logic
                     │
                     ▼
               MySQL Database
```

The Unity client does not directly access the database. All user authentication, player progress, quiz records, rankings, and persistent game data are securely managed through the Laravel backend.
